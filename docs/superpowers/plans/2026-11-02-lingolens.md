# LingoLens Implementation Plan

**Goal:** реализовать согласованный сценарий фото → слово → словарь.

**Architecture:** один Xcode-проект с отдельными сервисами камеры,
классификации, перевода и речи; SwiftUI-состояние экранов и SwiftData.

**Tech Stack:** Swift 6, SwiftUI, AVFoundation, Vision, Translation, SwiftData,
Swift Testing и XCUITest; iOS 18+.

Согласованный пользователем план выполняется последовательно в этом чате.
Спецификация: `../specs/2026-11-02-lingolens-design.md`.
