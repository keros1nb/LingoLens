# LingoLens Implementation Plan

**Goal:** реализовать согласованный сценарий фото → слово → словарь.

**Architecture:** один Xcode-проект с отдельными сервисами камеры,
классификации, перевода и речи; SwiftUI-состояние экранов и SwiftData.

**Tech Stack:** Swift 6, SwiftUI, AVFoundation, Vision, Translation, SwiftData,
Swift Testing и XCUITest; iOS 18+.

Согласованный пользователем план выполняется последовательно в этом чате.
Спецификация: `../specs/2026-11-02-lingolens-design.md`.

## 1. Минимальный проект и контроль распознавания

- [ ] Создать `LingoLens.xcodeproj`, app entry point, тестовый target.
- [ ] Определить `RecognitionCandidate`, нормализацию и выбор первых трёх
  уникальных результатов. Проверить сортировку, дубликаты и пустые результаты.
- [ ] Реализовать один общий сервис Vision для iOS и утилиты оценки на Mac.
- [ ] До запуска модели зафиксировать 30 изображений, правильные названия
  и допустимые синонимы в `docs/validation/recognition-manifest.json`.
- [ ] Собрать утилиту и выполнить оценку; записать все предсказания, версию
  ОС, revision Vision и результат порога 24/30 в `docs/validation/`.
- [ ] При результате ниже порога остановить следующие этапы и сообщить причину.

Команды: `swiftc -swift-version 6 LingoLens/Recognition/*.swift
Tools/VisionBenchmark.swift -o .validation/vision-benchmark`, затем
`.validation/vision-benchmark docs/validation/recognition-manifest.json
.validation/coco128 docs/validation/recognition-results.json`.

## 2. Перевод и речь — после прохождения контрольной точки

- [ ] Подключить `TranslationSession` через `.translationTask`, направление
  en → ru, проверку доступности и системный запрос загрузки моделей.
- [ ] Сохранить английское название при ошибке перевода; предоставить повтор.
- [ ] Подключить `AVSpeechSynthesizer` с английским голосом.
- [ ] Проверить перевод, отмену загрузки и офлайн на iPhone; явно отметить
  результат, если Developer Mode или устройство недоступны.

## 3. Камера и результат

- [ ] Добавить разрешение камеры, последовательную работу capture session,
  съёмку фото, остановку в фоне и восстановление при возвращении.
- [ ] Реализовать выбор из трёх кандидатов, перевод, озвучку, пересъёмку.
- [ ] Добавить целевые тесты состояний ошибки, повтора и смены кандидата;
  интерфейсные тесты использовать с тестовыми сервисами.

## 4. Словарь

- [ ] Добавить SwiftData-модель WordCard и сохранение фото в хранилище приложения.
- [ ] Нормализовать английское название для проверки повторного сохранения.
- [ ] Добавить список, детали, озвучку и удаление карточки.
- [ ] Проверить создание, повтор, удаление и повторное открытие хранилища.

## 5. Итоговые проверки

- [ ] Применить спокойный дизайн, системные адаптивные цвета и доступность.
- [ ] Запустить unit/UI tests и сборку для iPhone без подписи.
- [ ] Проверить на устройстве камеру, речь, офлайн-перевод, сохранение и фон.
- [ ] Зафиксировать реальные команды, результаты и ограничения в README.
