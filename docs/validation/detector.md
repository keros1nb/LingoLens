## Модель и условия использования

Выбрана готовая Core ML-модель **Apple YOLOv3Int8LUT**, около 62 МБ,
80 предметных классов. Сторонний SDK в приложение не добавляется; выполнение
через Core ML и Vision на устройстве. Модель включена в приложение и не
скачивается при запуске.

- [Официальная карточка Apple](https://huggingface.co/apple/coreml-YOLOv3)
  указывает `license: mit`.
- Встроенное поле лицензии самой модели отсылает к
  [оригинальному Darknet](https://github.com/pjreddie/darknet/blob/master/LICENSE),
  в котором Darknet объявлен public domain.
- Авторство и эти сведения сохранены в `LingoLens/Models/ModelNotices.txt`,
  оригинальный LICENSE включён рядом с моделью. Чужое авторство не изменено.
- Версия репозитория: `d9f596181a1eb1de924d07e1b47429391f30d80d`.
- SHA-256 модели: `0e32f297ad9cfc0ea8e67276867956488c7ee10dc87c057da4debc939e20b76d`.
- Код и веса Ultralytics YOLOv8 не используются. У них другой режим лицензирования.

## Протокол

Использованы **30 разных снимков COCO val2017** по одному из 30 бытовых
классов. Это другой набор, чем COCO128/train2017 первого этапа. Стандартная
конфигурация оригинального Darknet использует `trainvalno5k` для обучения;
val2017 служит стандартной проверочной частью COCO. Собственные фотографии
пользователя ещё не заменены этой лабораторной проверкой.

Снимки выбраны по существующей разметке до запуска детектора: первый по
имени файла подходящий снимок с площадью предмета от 15% кадра и центром
в диапазоне 0.15–0.85. Один исходный снимок не используется дважды.
Фиксированный crop по разметке с запасом 12% с каждой стороны приближает
сценарий одного предмета в центре. Неудачные примеры после запуска не заменялись.

- Изображения, ожидаемые названия и синонимы: `detector-manifest.json`.
- SHA-256 manifest: `c60ea26143a0c0fd8e37908eea8bde263a6ab7e78843e83e1f45d400a90f3249`.
- Контрольные суммы всех исходных изображений: `detector-image-sha256.json`.
- Подготовка manifest: `Tools/prepare-detector-benchmark.py`.
- Разметка: архив coco2017labels, SHA-256
  `51a5175c894a7a1010f90eb4cba613473445f02633b684ed46c0292a997d0234`.
- Исходные снимки загружаются по HTTPS из S3-хранилища COCO; они не входят в приложение.

Vision использует `.scaleFit`; NMS IoU 0.45, порог confidence 0.25.
Среди обнаруженных предметов сначала идут те, чья рамка содержит центр кадра,
затем учитывается confidence. Повторы одного названия удаляются; выводится
до трёх названий. Технические метки `pottedplant`, `diningtable`, `tvmonitor`
и `remote` преобразуются в понятные английские названия.

Оценка выполнена на Mac: Version 26.4 (Build 25E246).
Медианное время запроса вместе с подготовкой crop: 24.4 мс.
Это не измерение скорости камеры на iPhone и не обещание распознавания
произвольного предмета или общей точности 83%.
