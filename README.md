# LingoLens

Нативное приложение для изучения английских слов по фотографии предмета.
Swift 6, SwiftUI, минимальная версия iOS 18. В проекте нет сторонних зависимостей.

## Текущее состояние

**Реализован первый контрольный этап, приложение пока не готово.**
Созданы Xcode-проект, общий сервис Apple Vision, диагностический экран выбора
фото, целевые unit/UI-тесты и воспроизводимая проверка качества на 30 примерах.

Проверка Vision revision 2 дала **10/30** при требовании **24/30**. Согласно
согласованному плану разработка основного интерфейса остановлена до пересмотра
распознавания. Камера, перевод, озвучка и личный словарь ещё не реализованы.
Диагностический PhotosPicker предназначен для проверки модели, а не является
согласованным конечным интерфейсом приложения.

Подробности: [отчёт распознавания](docs/validation/recognition.md),
[дизайн](docs/superpowers/specs/2026-11-02-lingolens-design.md),
[план и контрольные точки](docs/superpowers/plans/2026-11-02-lingolens.md).

## Запуск

Откройте `LingoLens.xcodeproj`, выберите схему `LingoLens` и iPhone-симулятор,
нажмите Run. Диагностический экран позволяет выбрать снимок через системный
PhotosPicker и посмотреть три наиболее уверенных ответа Vision. Фотографии
не отправляются на сервер и не сохраняются приложением.

Для запуска на физическом iPhone выберите собственную команду в Signing &
Capabilities и включите на телефоне Настройки → Конфиденциальность и безопасность
→ Режим разработчика. На обнаруженном iPhone 17 Pro этот режим был выключен;
проверка на устройстве не выполнялась.

## Тесты и сборка

```sh
xcodebuild -project LingoLens.xcodeproj -scheme LingoLens \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  -derivedDataPath .build test CODE_SIGNING_ALLOWED=NO

xcodebuild -project LingoLens.xcodeproj -scheme LingoLens \
  -destination 'generic/platform=iOS' -configuration Release \
  -derivedDataPath .build-device build CODE_SIGNING_ALLOWED=NO
```

Проверка распознавания выполняется на Mac с macOS 14+ и Xcode:

```sh
bash Tools/benchmark.sh
```

Скрипт скачивает тестовый архив COCO128, проверяет его SHA-256 и запускает
тот же сервис распознавания, что используется приложением. Изображения находятся
в игнорируемой `.validation/`, в приложение не включаются. Полный отчёт пишется
в `.validation/recognition-results.json`. Код возврата **1** — качество ниже
порога, **0** — порог пройден. Ожидаемые названия зафиксированы в manifest;
они не генерируются ответами модели.

Результат Mac не заменяет проверку камеры и модели на iPhone. Реальный перевод
Apple Translation также потребуется проверять на устройстве после разрешения
контрольной точки распознавания.

Проверено 2 ноября 2026: 5 unit-тестов и 1 UI-тест прошли на iPhone 17 Pro
Simulator с iOS 26.4; Release-сборка для iPhone без подписи прошла. Проверка
качества Vision воспроизведена и завершилась ожидаемым отказом порога: 10/30.
