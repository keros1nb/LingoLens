# LingoLens

Приложение для iPhone: фотография предмета → английское название → русский перевод → личный словарь.

## Возможности

- До трёх названий на выбор, русский перевод и английское произношение.
- Сохранение слова с фотографией, просмотр и удаление карточек без дубликатов.
- Локальное распознавание и хранение. Аккаунт не требуется.

## Стек

iOS 18+, Swift 6, SwiftUI, AVFoundation, Core ML/Vision, Apple Translation, SwiftData.
Модели: CLIP ViT-B/16 и YOLOv3Int8LUT. Сторонних runtime-зависимостей нет.

## Запуск

1. Открыть `LingoLens.xcodeproj` в Xcode 26.4.
2. Выбрать свою команду подписи и уникальный Bundle Identifier.
3. Подключить iPhone с включённым Developer Mode и запустить схему `LingoLens`.

Для первой загрузки языков Apple Translation нужен интернет.

## Сборка

[IPA приложения](https://github.com/keros1nb/LingoLens/releases/latest).

IPA имеет Development-подпись и предназначен для зарегистрированного устройства.
Для другого iPhone требуется своя подпись. Срок действия указан в релизе.

## Проверки и ограничения

На iPhone прошли 22 теста логики и 3 теста устройства; на симуляторе — 22 теста логики и 4 UI-теста.
Распознавание: 28/30 на исходном наборе, 20/30 на дополнительном. Возможны ошибки.
Тренировок и синхронизации нет.
