The image encoder and precomputed text embeddings execute locally.
No OpenAI API, cloud service or runtime Python dependency is used.

SubjectNames.json is a modified vocabulary: normalized English names from
LVIS/Detectron2 and Open Images, with additional everyday household names.
Parenthetical dataset identifiers and underscores were removed, some synonyms
were normalized, and broad ancestor categories were excluded.

LVIS category names source:
https://github.com/facebookresearch/detectron2/blob/main/detectron2/data/datasets/lvis_v1_categories.py

The 1533 names are possible choices, not a guarantee that every photographed
object will be recognized. The models have not been trained on user photos.
Benchmark images are development data only and are not bundled with the app.
